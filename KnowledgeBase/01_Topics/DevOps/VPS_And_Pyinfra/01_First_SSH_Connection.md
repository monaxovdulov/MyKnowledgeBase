# Шаг 1. Первое подключение по SSH

> Карта трека: [[VPS_And_Pyinfra_MOC]] · Предыдущий: [[00_Overview]] · Следующий: [[02_SSH_Keys]]

Есть: IP, root, пароль от aeza. Делаем первый вход и сразу заводим своего пользователя — под root постоянно не работаем.

## Заходим под root

В Windows 10/11 клиент OpenSSH уже встроен — просто открываем PowerShell:

```powershell
ssh root@ВАШ_IP
```

- На вопрос про fingerprint отвечаем `yes` (параноики могут сверить отпечаток с данными в панели aeza).
- Вводим пароль root из панели.

Альтернативы, если `ssh` не находится: PuTTY или WSL.

## Создаём своего пользователя

Внутри SSH-сессии под root:

```bash
# sudo может не стоять на минимальном образе
apt update && apt install -y sudo

# создаём пользователя (спросит пароль — задай нормальный)
adduser roman

# добавляем в группу sudo
usermod -aG sudo roman
```

## Проверяем вход новым пользователем

**Не закрывая** root-сессию, открываем второе окно PowerShell:

```powershell
ssh roman@ВАШ_IP
sudo whoami    # после ввода пароля должно ответить: root
```

Если `sudo` сработал — root-окно можно закрывать. Если нет — чиним из оставшейся root-сессии.

## Если всё сломалось

Веб-консоль в панели aeza работает без SSH — заходим ею и чиним.

## Проверь себя

- [ ] `ssh roman@IP` пускает без ошибок
- [ ] `sudo whoami` → `root`
