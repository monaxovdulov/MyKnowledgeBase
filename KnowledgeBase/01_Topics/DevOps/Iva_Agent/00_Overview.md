# Iva — обзор и вердикт под кейс

**Iva** — self-hosted Telegram AI-ассистент с многослойной памятью
(Obsidian-совместимый vault). TypeScript, Node 24, фреймворк **eve**, лицензия MIT.
Репозиторий: https://github.com/smixs/iva-agent · сайт: https://iva-agent.com

## Что это физически

- Два systemd **user**-сервиса (не root, не docker): `iva-telegram-poll` (мост,
  long-poll к Bot API) + `iva` (eve-агент). Плюс два watchdog-таймера и семь
  внутрипроцессных eve-расписаний (ночная сборка памяти, напоминания и т.д.).
- Long-poll → **ни портов, ни домена, ни вебхука** не нужно. Живёт рядом с
  botops/Caddy без конфликтов — ничего наружу не слушает.
- Ставится одной командой `install.sh` под обычным юзером; Node 24 подтягивает
  через nvm, не трогая системный node.
- 512 MB RAM минимум → на giorno (4 GB) без проблем.

## Цены (провайдеры — на выбор, ключи твои)

| Вариант | Цена/мес |
|---|---|
| OpenCode Go (~23 модели, deepseek-v4-pro дефолт) | ~$5 |
| Ollama Cloud | ~$20 |
| OpenRouter (300+ моделей, pay-as-you-go) | по факту |
| OpenAI API-ключ → `MODEL_PROVIDER=custom` | по факту |
| Подписка ChatGPT → `MODEL_PROVIDER=codex` (OAuth, без API-ключа) | $0 сверху |
| Подписка Claude → `MODEL_PROVIDER=claude` | $0 сверху |

Плюс VPS $4–5 и опционально Deepgram (голос, стартовый кредит бесплатно) и
веб-поиск (tavily/exa — бесплатный тир).

## Вердикт под кейс «тьютор в топиках»

**Подходит, и хорошо:**

- Топики форума — первоклассные: каждый топик = отдельная сессия агента
  (своя история диалога). Разделение «топик заданий / топик решений» ложится
  на механику из коробки.
- Картинки/текст/файлы/голос принимает; картинки — через vision-модель
  того же провайдера.
- Расширение — markdown-файлами без пересборки (правила, скиллы) плюс
  кастомные tools/MCP/subagents под код.
- Память в markdown-vault — прогресс ученика и задания лежат файлами,
  читаются и правятся прозрачно.

**Ограничения, которые надо знать:**

- Один `MODEL_PROVIDER` на всё: главный агент, субагенты, helpers, vision —
  одна модель. «Оркестратор OpenAI + исполнители DeepSeek» нативно не
  разводится; путь — кастомный tool с прямым вызовом DeepSeek API (см.
  [[02_Tutor_Design]]).
- Доступ — allowlist по user_id: ученика придётся вписать, и тогда он
  технически сможет написать боту в личку (закрывается правилом, см. дизайн).
- Изоляция «ключ ответов от ученика» — на уровне промпта, не железная.

Детали механик — в [[01_Architecture]].
