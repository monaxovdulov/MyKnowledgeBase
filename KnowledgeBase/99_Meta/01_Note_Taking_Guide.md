# Как писать заметки в эту базу

> Руководство для авторов и агентов. Формальную проверку имён делает
> `Scripts/check_structure.py` — этот файл объясняет соглашения за ней.

## Структура папок

`KnowledgeBase/` — единственный корень контента. Верхний уровень — только
папки вида `NN_Name`:

| Папка | Назначение |
|-------|------------|
| `00_MOCs` | Карты содержимого (MOC) — «долгоживущие» обзорные документы: таблицы заметок трека/темы |
| `01_Topics` | Тематические заметки; внутри темы — треки/подпапки |
| `02_References` | Справочники и реестры (Tools и т.п.) |
| `03_Projects` | Проекты |
| `04_Courses_and_DeepDives` | Курсы и глубокие разборы |
| `05_BlogDrafts` | Черновики постов |
| `06_Templates` | Шаблоны заметок |
| `99_Meta` | Мета-документы о самой базе (этот файл) |

Плюс файл `00_MasterIndex.md` в корне `KnowledgeBase/` — общий индекс базы.

## Имена

- Папки верхнего уровня: `^\d{2}_.+` (две цифры + подчёркивание + имя).
- Файлы `.md`: `^[A-Za-z0-9_-]+\.md$` — латиница, цифры, `-`, `_`; **без пробелов**
  и без кириллицы в имени (кириллица — только внутри текста).
- Заметки трека нумеруем внутри темы: `00_Overview.md`, `01_First_SSH_Connection.md`…
  Порядковый номер задаёт порядок чтения.
- Разрешённые расширения: `.md`, `.canvas`, `.excalidraw`, `.png`, `.jpg`, `.jpeg`, `.gif`.

## Атомарность и связи

- Одна заметка = одна идея/шаг/понятие. Большое дробим.
- Связи — только wikilinks `[[Имя_файла]]` (Obsidian).
- Каждый трек/тема собирается в MOC в `00_MOCs/` — таблица «номер → заметка → что даёт».
- Теги в конце файла: `#vps #debian`.

## Журналы практики (Practice_Log)

Треки, которые проходятся на живом железе, ведут `Practice_Log.md` в папке трека:

- Хронология фактических действий: команды, вывод терминала, затыки, уроки.
- **Блок «Текущее состояние» в самом верху** — точка восстановления для нового
  агента/сессии: что сделано, что нет, следующий шаг. Обновлять при каждом
  изменении состояния.

## Workflow для агента

1. Прочитать нужный MOC в `00_MOCs/` → нужные заметки.
2. Писать/править по правилам выше; новую заметку вносить в таблицу MOC.
3. Прогнать `python3 Scripts/check_structure.py` (из корня репо).
4. Коммит прямо в `main`, сообщение осмысленное (en), пуш.
5. Пароли, ключи, токены в базу не писать никогда.
