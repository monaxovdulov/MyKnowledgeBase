# IVA Pi Tutor

Небольшой Telegram-тьютор на Pi Agent Core. Telegram Bot API вызывается напрямую через Node `fetch`, без тяжёлого Telegram SDK. Модель — облачный OpenAI API, Pi выполняет агентный цикл. Режимы учителя и ученика разделены кодом: в промпт ученика не попадает поле `privateAnswer`.

## Запуск

1. Установить Node.js 24.
2. `cp .env.example .env`, выставить права `chmod 600 .env` и заполнить бота, IDs группы и топиков, `OPENAI_API_KEY` и `OPENAI_MODEL`.
3. `npm install`
4. Проверить настройки без подключения к Telegram: `npm start -- --check`.
5. Запустить: `npm start`.

Для постоянного запуска скопировать `systemd/iva-pi-tutor.service` в `~/.config/systemd/user/`, затем выполнить `systemctl --user daemon-reload`, `systemctl --user enable --now iva-pi-tutor.service`. Юзерский systemd и `linger` уже есть на `giorno`. После обновления Node поправить путь в `ExecStart`.

Первый прототип принимает текст и изображения в топике заданий, создаёт активную карточку и проводит ученика пошагово в топике решений. Состояние хранится в `data/state.json` (`0600`), эталонный ответ отдельно в `data/private/answer.txt` (`0600`); каталог данных исключён из Git. В коде тьютор получает только поля карточки без эталонного ответа.

Требуется включённый Telegram Topics, бот должен состоять в группе. При стандартном Privacy Mode Telegram доставляет боту команды, упоминания и ответы на его сообщения. Используйте `@bot` или reply.

Перед постоянным запуском нужно пройти ручной приёмочный сценарий, отдельно проверить доступ по IDs, оба топика, ввод картинки, начисление баллов и секретность эталонного ответа. Это ранний прототип; автоматическая оценка ответа моделью не является криптографической гарантией.
