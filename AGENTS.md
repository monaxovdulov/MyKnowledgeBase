# AGENTS.md — точка входа для агентов

Это Obsidian-база знаний (контент на русском). Дерево «долгоживущих документов»
— папка `KnowledgeBase/00_MOCs/`: начинай работу с просмотра нужного MOC и уже
оттуда иди в атомарные заметки (принцип progressive disclosure: MOC → заметка →
детали, не читай всё подряд).

## С чего начать сессию

1. `ls KnowledgeBase/00_MOCs/` — список карт; открой нужный `*_MOC.md`.
2. Активная практика идёт в `Practice_Log.md` внутри папки трека — его верхний
   блок **«Текущее состояние»** говорит, где мы и что делать дальше.
3. Перед созданием/правкой заметок прочитай
   `KnowledgeBase/99_Meta/01_Note_Taking_Guide.md` — правила имён, атомарности,
   связей и журналов.

## Правила работы

- Пишущаяся работа — на русском; имена файлов — латиница без пробелов.
- После каждого фактического шага пользователя: объяснить → записать в
  `Practice_Log.md` (включая затыки и их решения) → обновить блок «Текущее
  состояние» → коммит и пуш в `main`.
- Перед коммитом обязательно: `python3 Scripts/check_structure.py`.
- Коммиты прямо в `main`, без PR.
- Пароли, приватные ключи, токены — никогда в репозиторий.
